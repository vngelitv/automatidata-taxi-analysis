# Course 3 – Statistical Analysis

This folder contains the statistical analysis phase of the Automatidata NYC Taxi project.

## Work Completed

- Compared fare amounts by payment type
- Calculated descriptive statistics
- Formulated null and alternative hypotheses
- Conducted a two sample t-test
- Evaluated statistical significance at the 5% level
- Interpreted results for business stakeholders

## Key Finding

The hypothesis test found a statistically significant difference in average fare amount between credit card and cash payments.

The p-value was approximately `6.80e-12`, which is far below the 0.05 significance level, so the null hypothesis was rejected.
