# Course 4 – Multiple Linear Regression

This folder contains the regression modeling phase of the Automatidata NYC Taxi project.

## Work Completed

- Performed exploratory data analysis before modeling
- Converted pickup and drop-off timestamps to datetime
- Created trip duration features
- Identified and handled outliers
- Engineered mean trip distance and mean trip duration features
- Created day, month, and rush-hour variables
- Examined correlations between predictors and fare amount
- Split the data into training and testing sets
- Standardized predictor variables
- Built a multiple linear regression model
- Evaluated model performance using R², MAE, MSE, and RMSE
- Analyzed residuals and model coefficients

## Key Findings

- Mean trip distance and mean trip duration were strongly associated with fare amount.
- The regression model explained a large portion of the variation in taxi fares.
- Training performance showed an R² of approximately 0.84.
- Residual analysis helped assess whether the model assumptions were reasonably satisfied.
- The model can be used as a foundation for predicting taxi fares from trip-related characteristics.
